# Wallet Actions

Wallet actions expose spend and SYSTEM bonus workflows.

## Access Rules

| Action | USER | SYSTEM |
|---|---:|---:|
| Spend credits | Yes | No |
| Issue bonus | No | Yes |

## Spend Flow

```mermaid
sequenceDiagram
    autonumber
    participant User
    participant Web
    participant Gateway
    participant Service

    User->>Web: Enter amount, asset, description
    Web->>Web: Generate idempotency key internally
    Web->>Gateway: POST /api/v1/wallets/spend
    Gateway->>Service: Forward request
    Service-->>Gateway: transaction response
    Gateway-->>Web: result
```

Spend asset dropdown contains only:

```text
GOLD
DIAMOND
```

LOYALTY is excluded from spend UI.

## Bonus Flow

```mermaid
sequenceDiagram
    autonumber
    participant System as SYSTEM user
    participant Web
    participant Gateway
    participant Service

    System->>Web: Select target user from dropdown
    System->>Web: Select asset and amount
    Web->>Web: Generate idempotency key internally
    Web->>Gateway: POST /api/v1/wallets/bonus
    Gateway->>Service: Forward request
    Service-->>Gateway: transaction response
    Gateway-->>Web: result
```

Bonus asset dropdown contains:

```text
GOLD
DIAMOND
LOYALTY
```

## Idempotency Rule

Idempotency keys are generated by the UI and hidden from the user. Manual editing is intentionally removed to avoid accidental duplicate-key misuse and operator confusion.
